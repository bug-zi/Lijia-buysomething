# 全自动个人购物 AI 助手（ShoppingAgent）

一个运行在个人电脑本地的**对话式购物决策 Agent**。用自然语言说出购物需求（如「买一条夏天的连衣裙，预算200以内」），系统完成 **建档 → 需求解析 → 选品 → 评价分析 → TOP3 推荐 → 购物车/比价 → 下单模拟 → 物流跟踪 → 售后** 全流程辅助。

> ⚠️ **支付红线**：本系统只做下单流程**模拟**（生成订单号），**绝不代用户支付**，也不连接任何真实支付渠道。

## 特性亮点

- **零第三方依赖启动**：后端基于 Python 标准库 `http.server`，前端为单文件 `index.html`，双击 `.bat` 即可运行；
- **AI 增强可选、全链路兜底**：LLM 仅做增强（解析/摘要/润色），不做事实决策；任何 AI 调用失败都静默回退到规则引擎，功能永不因 AI 失效而中断；
- **真实数据优先、绝不编造**：数据源三层回退（真实抓取缓存 → Playwright 真实浏览器抓取 → 演示 Mock），每条商品带 `data_source` 标注（📦 真实 / ⚠️ 演示）；
- **人机协作抓取**：受电商反爬限制，采用「用户粘贴 1-5 个商品详情链接 → Agent 逐个抓取打分」的协作模式；遇验证码暂停交还人工，回复「继续抓取」续跑，绝不批量遍历或绕过平台验证；
- **个人持久档案驱动推荐**：约 27 个字段的用户偏好档案（尺码/色系/风格/材质/预算等）作为打分的永久参考；
- **多服务商 LLM**：OpenAI 兼容协议，自动探测智谱 / DeepSeek / 通义千问 / 硅基流动 / 豆包 / Kimi，视觉任务自动切换视觉模型；
- **API Key 安全**：Key 仅本地存储且脱敏展示（前后 4 位），绝不回传前端明文。

## 快速开始

### 环境要求

- Windows 10/11
- Python 3.9+（安装时勾选 *Add Python to PATH*）

### 启动

| 方式 | 操作 | 说明 |
|---|---|---|
| **网页版（推荐）** | 双击 `启动购物助手-网页版.bat` | 启动本地服务并自动打开浏览器，地址 `http://127.0.0.1:8765/`，仅本机可访问；关闭窗口即停止服务 |
| **命令行版** | 双击 `启动购物助手.bat` | 终端对话，支持 `python shopping_agent.py demo` 跑 18 个演示用例全流程回归 |

两个脚本均内置 4 层 Python 解释器探测兜底，错误日志写入 `%TEMP%\shopping_agent_web_error.log`（网页版）/ `%TEMP%\shopping_agent_error.log`（CLI）。

### 可选：开启真实抓取

不安装 Playwright 也能完整体验（走演示 Mock 数据，带 ⚠️ 标注）。要抓取真实商品页：

```bash
pip install playwright
playwright install chromium
```

### 可选：配置 LLM（AI 增强）

在网页版「AI 设置」Tab 中填入任一服务商的 API Key 即可；也可以用环境变量：

```bash
set SHOPPING_LLM_API_KEY=你的key
set SHOPPING_LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
set SHOPPING_LLM_MODEL=glm-4-flash
```

不配置 Key 不影响任何功能——所有 AI 环节自动回退规则引擎。默认推荐免费档模型（如智谱 `glm-4-flash`）。

## 使用示例

```text
你：买一条夏天的连衣裙，预算200以内
AI：（解析需求 → 输出搜索关键词）请粘贴 1-5 个商品详情链接…
你：（粘贴淘宝/京东/拼多多/抖音的商品链接）
AI：（逐个抓取 → 五维打分 → TOP3 推荐：优缺点/价格分析/适配说明/评分表/横向对比）
你：买第2款
AI：（订单草稿预览 + 支付风险提醒）确认下单吗？
你：确认
AI：（模拟下单，生成订单号与运单号 → 物流随时间推进 → 已签收后可发起售后）
```

支持增量调整（「第二款太宽松，换更修身的，预算升到300」直接叠加修改）、快捷档案命令（「查看档案 / 修改身高=175 / 录入档案 / 继续建档」）、购物车与降价监控、图片找同款与多图对比等。

## 五维评分模型

加权总分 0-100（`recommender.py`）：

| 维度 | 权重 | 说明 |
|---|---|---|
| 档案匹配度 | 30% | 色系/风格/材质/版型/尺码/品牌/讨厌元素/发货地区 |
| 性价比 | 25% | 折扣率 + 销量 + 预算贴合 |
| 真实口碑 | 20% | 好评率 + 带图追评占比 + 评价量 |
| 差评风险 | 15% | 差评点数量与严重词命中 |
| 发货时效 | 10% | 发货天数 + 自营/次日达加成 |

## 项目结构

```text
├── 启动购物助手-网页版.bat   # 网页版一键启动
├── 启动购物助手.bat          # CLI 一键启动
├── shopping_agent.py         # 主 Agent 总控 ChatSession：意图分流、工作流串联
├── web_server.py             # HTTP 后端：13 个 API 端点、静态托管（绑定 127.0.0.1）
├── index.html                # 前端单页：6 个 Tab（对话/档案/订单/购物车/推荐/AI设置）
├── request_parser.py         # 需求解析规则引擎 + LLM JSON 增强
├── product_searcher.py       # 商品模型、三层回退搜索、演示 Mock 目录、抓取缓存
├── web_scraper.py            # Playwright 单链接详情页抓取（反爬检测、字段提取）
├── recommender.py            # 五维评分、TOP3 格式化、AI 点评接入
├── order_manager.py          # 下单模拟、物流虚拟推进、售后/取消
├── profile_module.py         # 偏好档案：19 批次分步引导录入
├── virtual_cart.py           # 购物车 CRUD、降价监控
├── ai_client.py              # LLM/视觉调用、Key 探测与脱敏、失败回退
└── docs/                     # 项目文档库（见下）
```

## 安全与合规设计

- **绝不代用户支付**：仅模拟下单流程，确认前后均有支付风险提醒；
- **数据真实**：绝不编造商品数据，真实/演示双标注，抓取失败如实告知；
- **抓取克制**：只抓用户主动粘贴的 1-5 个链接、真实有头浏览器、遇验证码交还人工、禁止批量遍历、不绕过平台风控；
- **隐私本地化**：全部数据存本机 JSON 文件，服务只绑定 `127.0.0.1`，Key 脱敏展示。

## 已知限制（如实告知）

- **历史价格曲线不支持**：仅做当前价横向对比；
- **图片分析仅为视觉推测**：不保证准确，以商品网页为准；
- **真实抓取成功率**受电商平台风控波动影响，抓不到时会明确告知并回退演示数据。

## 开发与测试

- 全流程回归：`python shopping_agent.py demo`（18 个演示用例）；
- 各模块自带 `__main__` 自测入口，如 `python recommender.py`；
- 部署形态：单机单进程，升级 = 替换文件重启 `.bat`。
