# log/ — 开发日志目录

每天一个开发日志文件，命名 `YYMMDD.md`（如 `260911.md`），由 AI 维护。

## 规则

- **小节按创建时间由新到旧排列（最新在最上）**（开发者指令 2026-09-12）：追加新小节时按时间插入到正确位置，不盲目追加到文末；文件整体保持倒序
- **每个小节标题下必须附创建时间行**：`> 创建于 YYYY-MM-DD HH:MM`，用 `date` 命令实取，不估不编
- 小节结构：标题（功能名 + 来源 + 范围）→ **需求** → **设计定稿**（含设计文档路径）→ **实施** → **验证** → **涉及文件**
- 归档动作、落地判定等触发时机见 `../project/README.md`；历史日志中的旧路径引用不改写
