## 抓取被拦截问题修复（问题疑惑区第1轮，web_scraper）

> 创建于 2026-09-12 00:41

**需求来源**：`docs/project/问题疑惑区.md` 待完成问题——天猫链接抓取 `Page.goto` 30s 超时（截图 `resource/网络抓取异常.png`）；开发者同时询问能否用 MCP/云端浏览器工具（如 Tavily）解决。

**方案商讨**：给出 A（修现有 Playwright 链路）/ B（CDP 接管本机已登录 Chrome）/ C（云端 API，不推荐：无登录态、机房 IP、隐私外发）三案，开发者选定方案 A。

**诊断过程**：
1. modlens 读取截图：纯白页面，`domcontentloaded` 30s 无响应；
2. 代码核查（codegraph + Read）：UA 硬编码 Chrome/124 与捆绑 Chromium 版本不匹配；goto 单次尝试；超时落「抓取异常」而非「交还人工」；
3. 实测：真实 Chrome 打开京东/天猫/淘宝首页全部正常 → 网络与指纹无问题；**原链接为直通车广告追踪链接（`ali_refid/ali_trackid/xxc=ad_ztc`），有时效与用户绑定，过期后即网络层黑洞**——结论：换任何工具都抓不到失效链接，问题主因是链接失效 + 旧链路对真实拦截无兜底。

**实施**（仅改 `web_scraper.py`）：
- 新增 `_find_system_browser()`：探测本机 Chrome/Edge，`_launch_browser` 优先 `channel` 启动真实浏览器（UA 不再覆盖、跟随真实浏览器），channel 启动失败回退捆绑 Chromium；`_check_browser_binaries` 同步接受系统浏览器；
- 新增 `_goto_with_retry()`：`domcontentloaded` 30s → `commit` 45s 两段式重试；
- 新增 `_save_failure_screenshot()`：失败截图存 `temp/`（已在 .gitignore）；goto 超时与验证码同样「交还人工」（block_reason 含「继续抓取」触发续跑、need_human=True 停止后续链接），与 `shopping_agent._flow_grab_and_compare` 的续跑契约对齐。

**验证**：模块导入自测通过；本机检测到真实 Chrome；真实 Chrome 启动 + 京东首页加载冒烟通过；用原始失效链接实测——两段式重试均超时后正确输出「交还人工」提示并留存截图（`temp/scrape_fail_20260912_003912.png`），续跑契约生效。

**遗留**：开发者需用**新鲜**商品链接做最终验收；若新鲜链接仍被拦截，升级方案 B（CDP 接管）。

## 启动脚本重写（修复双击无响应 / cmd 报「此时不应有 >。」，全栈启动层）

> 创建于 2026-09-12 00:47

**需求来源**：开发者反馈双击 `.bat` 无响应，`cmd /c` 调用报 `此时不应有 >。`；后要求放弃修补、直接换更简单的启动方式。

**诊断过程**（多次实测复现）：

1. 原症状复现：原版网页版 bat 一执行即报 `此时不应有 >。` 并终止（解析期致命错误，pause 都执行不到，故双击表现为闪退）；
2. 纯 ASCII 最小复现不报错 → 排除 bat 逻辑本身，锁定编码问题：**bat 文件为 UTF-8，而中文 cmd 默认按 GBK 解析**，中文注释的 UTF-8 字节流在 GBK 下错位成对（lead+trail 吞掉后续 ASCII），行边界丢失、语法碎片化；
3. 试验「首行提前 chcp 65001」无效；改存 GBK 后经 `call` 传递仍碎裂（与测试管道叠加干扰）；
4. 另发现两个叠加 bug：`for /f ... in ('...')` 命令串内嵌 `sep='.'` 单引号破坏 for 定界；本机 `py` 启动器损坏（PEP-514 无注册，报 No installed Python found!），真机可用的是 `python` = `D:\app\Python\python.exe`。

**设计定稿**：放弃修补原脚本，按开发者指示重写为**纯 ASCII 极简启动脚本**——中文只允许出现在文件名，文件体禁用一切非 ASCII；Python 探测改为「先实测（`-c "import sys"`）再采用」的 py→python→python3 链。

**实施**（仅重写两个 bat，业务代码零改动）：

- `启动购物助手-网页版.bat`：探测链 → 启动 `web_server.py`（默认端口 8765）→ 失败时 pause + 指引日志位置
- `启动购物助手.bat`：同结构 → 启动 `shopping_agent.py`（透传 `%*`，`demo` 参数可用）
- `CLAUDE.md` 全局硬性规则新增「启动脚本编码红线」条目

**验证**：网页版经 GBK 中转真实调起——横幅、探测（自动落到 python）、服务启动全部正常，`GET /api/health` 返回 `{"ok": true}`，测毕已停服务；CLI 版与网页版同构，未做交互端到端（避免挂起），`demo` 回归待开发者双击自测。测试残留（临时 relay/副本/测试服务器）已全部清理。

**涉及文件**：`启动购物助手.bat`、`启动购物助手-网页版.bat`、`CLAUDE.md`、本文档。
