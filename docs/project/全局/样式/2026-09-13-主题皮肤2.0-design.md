# 主题皮肤 2.0：背景图皮肤化 + 深色模式去黑化（spec）

> 创建于 2026-09-13 22:19（开发者发起返工，AI 起草）
> 状态：已实施（2026-09-13，对比度 48 项断言 ALL PASS、8 组合截图自测通过；含验收反馈追加的「设计 4 侧栏模式化」；订单状态盒/下单确认弹窗为代码级验证，待开发者验收）
> 来源：T3（深浅色模式+四套皮肤，commit 7c399f2）验收返工——开发者查收后提出两点不满意：① 背景图直接沿用了上传的两张 PNG（粉/蓝绑死），未按皮肤色系适配，上传图仅作风格参考；② 深色模式用中性黑灰「很丑、不够协调」，要求改为「浅色模式浅皮肤色+黑字、深色模式深皮肤色+白字」（如红色主题：浅色用浅红、深色用深红）。

## 背景与决策

- 现状（v1.0 遗留）：壁纸为 `resource/bg-light.png`（淡粉樱花）/ `bg-dark.png`（深蓝夜樱）两张固定 PNG，经 `body::before` 蒙 50%/55% 透明度 + `body::after` 皮肤色渐变扫角；表面色（bg/card/气泡/边框/文字）只有一套中性值，深色模式为近黑的中性蓝灰（`#12151c`/`#1b2029`），与任何皮肤色相都无关。
- 组合矩阵：4 皮肤（classic 经典蓝 / sakura 樱花粉 / forest 森野绿 / sunset 暖阳橙）× 2 模式 = 8 套组合；用户中心选色即选皮肤（`UC_COLORS` 与皮肤一一对应），本期不动该映射。
- 方案选型（三选一，开发者已定）：**方案 A——内联 SVG 装饰层 + CSS 变量着色**。一张 SVG 构图内嵌 `index.html`，所有填色/描边引用 CSS 变量，由皮肤×模式 CSS 块定义，自动获得 8 种配色，未来新增皮肤零成本，且不破坏单文件前端约束。已否决：方案 B（Python 脚本生成 8 张 SVG 文件——换肤靠切文件、新增皮肤需重跑脚本）、方案 C（纯 CSS 渐变光斑——无画面感，与参考图风格差距大）。
- 深色浓度选型（三选一，开发者已定）：**明显带色相档**——深色底明度约 12%（如深酒红/深松绿/深海军蓝），一眼可辨皮肤色系，低饱和不刺眼，白字对比度充裕。已否决：更深含蓄档（明度 7-9%，色相辨识弱）、中等彩底档（明度 18-22%，大面积彩底易疲劳、对比度难保证）。

## 设计 1：背景装饰层（内联 SVG + CSS 变量）

- 移除 `body::before`（PNG 壁纸）与 `body::after`（渐变扫角）两层，替换为一个内联 `<svg class="bg-deco">`：
  - `position: fixed; inset: 0; z-index: -1; pointer-events: none`，与现壁纸同为内容之下、body 背景之上；
  - `viewBox="0 0 1600 900"` + `preserveAspectRatio="xMidYMid slice"`，任意窗口尺寸完整覆盖；
  - 静态无动效，无 JS 依赖，模式/皮肤切换纯靠 CSS 变量级联生效。
- 构图沿用参考图的风格语言：**角部主题元素 + 边缘散落小元素 + 中心大面积留白**（内容区可读性优先），以 feGaussianBlur 柔焦光斑营造水彩氛围。
- 四套皮肤各用主题母题：
  | 皮肤 | 母题 |
  |---|---|
  | classic 经典蓝 | 气泡光点 + 细波浪线 |
  | sakura 樱花粉 | 五瓣樱花 + 飘落花瓣（最贴近参考图） |
  | forest 森野绿 | 叶片 + 枝条 |
  | sunset 暖阳橙 | 落日光晕 + 暖光斑 |
- 着色变量（SVG 内 fill/stroke 全部引用，禁止硬编码色值）：`--deco-strong`（主元素）、`--deco-mid`（次元素）、`--deco-soft`（柔焦光斑）、`--deco-line`（线条/叶脉等细节）。
- 两态基调：
  - 浅色模式：装饰用皮肤色**浅调**、低透明度，若隐若现；
  - 深色模式：装饰用皮肤色**亮调**、低透明度，复刻深色参考图「夜里微光」的质感。

## 设计 2：深色模式去黑化（深皮肤色 + 白字）与浅色模式染色

CSS 结构调整：表面色从「一套中性值 + 皮肤只覆盖强调色」改为**每个皮肤定义自己的浅色表面 + 深色表面**：

- `[data-skin="X"]`：该皮肤浅色表面（`--bg` 浅皮肤色、`--card` 近白微染、`--chat-bg`/`--ai-bubble` 同色相浅调、`--border` 皮肤色低饱和中间调、`--text-1/2/3` 深皮肤色灰调近黑）+ 强调色（沿用现有）+ `--deco-*` 浅色值；
- `[data-skin="X"][data-mode="dark"]`：该皮肤深色表面（`--bg` 深皮肤色、card/气泡比 bg 提亮 1-2 档同色相、`--border` 亮调低透明、`--text-1/2/3` 白→灰白微染皮肤色相、阴影加深）+ `--primary` 提亮一档 + `--deco-*` 深色值；
- `:root` 仅保留共享默认（radius/font/语义色）并兼任 **classic 浅色表面**（即 classic 兜底）；块结构为「其余 3 皮肤浅色 + 4 皮肤深色」共 7 个覆盖块，合计 8 套组合完整定义，中性灰阶表面值全部移除，杜绝回退到中性黑。

色板基线（实施时以对比度实测微调；明度按已定的 ~12% 档）：

| 皮肤 | 浅色 bg / 正文 | 深色 bg / 正文 |
|---|---|---|
| classic 经典蓝 | `#eef4fb` / 深藏蓝黑 | `#0e1a2e` / `#e9eef7` |
| sakura 樱花粉 | `#f9eff3` / 深酒褐 | `#2a161f` / `#f5e9ee` |
| forest 森野绿 | `#eff6f1` / 深松墨 | `#12211a` / `#e8f1ec` |
| sunset 暖阳橙 | `#f9f2e8` / 深赭褐 | `#241a10` / `#f4ece0` |

- 对比度要求：正文 text-1 对 bg ≥ 7:1；次要文字 ≥ 4.5:1；深色模式 `--primary` 取中间调——深底上可读、实底按钮白字 ≥ 3:1（大字号标准；实施修正：原「提亮一档保 ≥4.5:1」机制写反，提亮反而降低白字对比）；用作文字的 `--primary-dark` 在深色下转为亮色调（对 card ≥ 4.5:1）；warn/success/danger 语义色沿用现有深色 rgba 方案，在彩底上逐屏验证可读性，不达标再微调。
- 遵守配色规范：所有新色值低饱和、与主题色同色系，禁止彩亮饱和色。

## 设计 3：范围与连锁影响

- **不改**：四套皮肤主题色本身、布局结构、侧栏渐变（已皮肤化）、用户气泡渐变（`--ub-1/2`，深色下如违和仅微调透明度）、首屏防闪白脚本（仍按 `data-mode`/`data-skin` 属性切换）、用户中心选色逻辑、后端任何代码。
- **硬编码收编**：通查 `index.html` 残留的中性硬编码色（灰阶、`rgba(0,0,0,…)` 阴影/遮罩等），在深色彩底下违和的收编进变量；T3 已收编一轮，预计残留有限。
- 废弃变量：`--app-bg`、`--bg-img-opacity` 删除；`resource/bg-light.png`、`bg-dark.png` 不再被引用，**文件保留不删**（是否删除由开发者决定）。
- 兜底：CSS 变量均有 fallback 色值；装饰层为静态内联 SVG，无加载失败路径，不影响任何功能链路（AI 兜底红线无关涉）。

## 验证方式（实施完成标准）

本地起服务，浏览器实测 **4 皮肤 × 2 模式 = 8 种组合**逐一截图检查：

- 装饰层与卡片/气泡协调，中心留白区正文可读；
- 正文/按钮/边框对比度达标（按设计 2 阈值抽查）；
- 界面覆盖：主对话界面、登录层、弹窗（下单确认等）、用户中心四类各过一遍；
- 皮肤/模式切换即时生效、无闪烁、刷新后持久（localStorage 链路回归）。

## 设计 4：侧栏模式化（验收反馈追加，已实施）

- 原状：侧栏为固定的深→浅主题色渐变（`--sidebar-grad`）+ 白字 + 白色选中胶囊，不随模式变化。
- 改为**透明玻璃**（开发者经临时调参器实测定稿 0%）：背景全透明 + `backdrop-filter: blur(14px)`，装饰层完整透出侧栏、全窗背景连续；右侧 `1px solid var(--border)` 分隔线保留。调参过程：78% → 74% → 调参器（0-100% 实调）→ 开发者定稿 0%，调参器已删除。
- 品牌区：logo 方块保留主题渐变（`--user-bubble`）+ 白图标作唯一点缀，尺寸 36×36（原 42，按开发者要求缩小）；标题单行「购物AI助手」（副标题「Personal Shopping Agent」按开发者要求删除）；`.brand` 去横向内边距，**下划线与导航项左右边缘对齐**（brand 14→245 = 导航项 14→245；选中项自带 translateX(2px) 右移动效除外）；品牌区定高 44px + 侧栏顶部内边距 12px，**下划线与顶栏底线精确齐平**（实测两侧 bottom 均 = 56px，连成一条横贯整窗的直线）；分隔线 `--border`。
- 顶栏同步 0% 全透明（`background: transparent` + `blur(14px)`，保留底部 `--border` 发丝线），全窗顶部背景连续；至此顶栏/侧栏均为纯毛玻璃，表面色只存在于内容卡片与组件。
- 导航项：默认 `--text-2`；hover = `--mute-bg`；**选中 = `--primary-soft` 底 + `--primary-dark` 字**（两种模式全靠变量自适应，删除原「深色下选中项改用 --primary」特例规则）。
- footer：文字 `--text-3`、代码标签 `--mute-bg`+`--text-1`、分隔线 `--border`；侧栏内全部 `rgba(255,255,255,…)` 硬编码清零，`--sidebar-grad` 四处定义删除。
