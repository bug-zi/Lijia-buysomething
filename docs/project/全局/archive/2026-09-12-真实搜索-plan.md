## 任务分解（按序执行）

### T1 web_scraper.py — 搜索页抓取层
- 平台常量 `SEARCH_SITES`：京东/淘宝的搜索 URL 模板 + 卡片与字段 selector 候选列表；
- `search_platform(keyword, platform, max_results=8)`：
  启动（复用 `_launch_browser`）→ `_goto_with_retry` 搜索页 → 登录墙检测（`_detect_block` + 登录 URL 特征）→ 慢速滚动促发懒加载 → 逐卡片提取（多 selector 候选，缺省留空）→ 返回 cards；
- 登录墙 → `need_human=True`，block_reason 含「继续抓取」；
- 头部 docstring 反爬规则同步替换为新条款。

### T1.5 web_scraper.py — Patchright 反拦截基座（2026-09-12 修订新增）
- 导入兜底链：`try: from patchright.sync_api import sync_playwright` → `except ImportError` 回退原版 `playwright`；`_has_playwright()` 同步兼容（两者任一可用即可）；`_launch_browser` 改用兜底链解析出的模块，其余启动参数不变（持久化 profile、真实 Chrome channel 优先、有头——即 Patchright 官方推荐配置，无需调整）；
- `patchright` 与 playwright 同列为**可选依赖**：缺失仅降级为原版 playwright，不阻断启动；如需捆绑驱动用 `python -m patchright install chromium`；
- 头部 docstring 补反拦截说明：指纹级规避（修补框架自身指纹），不绕过验证码/风控；
- 参考 selector 补充候选：[MarketSpider](https://github.com/zhangjiancong/MarketSpider)（淘宝/京东/1688 搜索卡片 selector，仅作候选参考，失效不依赖）。

### T2 product_searcher.py — 卡片转 Product + 入口
- `_build_product_from_card(card, platform)`：字段映射，`data_source="真实"`，评价字段留空；
- `search_real(keyword, platforms, price_min, price_max, max_per_platform)`：逐平台调 `search_platform`，聚合 `(products, block_reason, need_human)`；异常单平台跳过并记原因。

### T3 shopping_agent.py — 新工作流与分流
- `_flow_search_and_recommend(request)`：search_real → 预算初筛 → `recommend_from_products` → `format_top3`（附「真实数据」提示与图片）；
- `chat` 分流：有 URL → 原链接流程；有结构化需求 → 新搜索流程；不足/拦截 → 如实提示 + pending 续跑；
- 「继续抓取」扩展：有 `_pending_search` 时续跑搜索，否则维持原重抓逻辑。

### T4 规则文档更新
- CLAUDE.md「抓取克制」条目替换为新条款；
- CLAUDE.md「技术约束」可选依赖表述更新为「Playwright/Patchright 为可选依赖（Patchright 缺失回退原版）」；

### T5 验证与归档
- 模块自测 + `python shopping_agent.py demo` 回归；
- 京东真实搜索冒烟（关键词「运动鞋」，预算过滤后 ≥3 条、含图片 URL）；
- 淘宝登录墙：未登录触发 need_human 提示（自动化可验），扫码续跑由开发者验收；
- Patchright 回退回归：模拟 patchright 缺失（临时卸载或 mock 导入失败），demo 与京东冒烟仍走原版 playwright 通过；
- 京东风控观察：接入 Patchright 后搜索冒烟不触发滑块/风控页（若触发，按既有机制截图并交还人工，如实记录）；
- `docs/log/260912.md` 追加小节；本 spec/plan 落地后按机制移入 `archive/`。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 平台改版导致 selector 失效 | 多候选 selector + 缺省留空；失效时如实提示并回退「粘贴链接」旧路径 |
| 淘宝扫码流程打断会话 | pending 状态持久在会话内存，「继续抓取」续跑；profile 持久化保证后续免扫码 |
| 搜索请求被风控黑洞 | 两段式 goto + 失败截图 + 交还人工（既有机制） |
| Mock/demo 链路回归破坏 | 新流程独立入口，不改动 Mock 路径；demo 全量回归验证 |
| patchright 维护滞后 / API 兼容风险 | drop-in 替换、API 兼容风险低；导入兜底链保证随时可回退原版 playwright |
